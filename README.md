# Beehiiv Playwright Friend

This project is a lightweight automation toolkit built using Playwright and Node.js to simplify and automate routine tasks on the Beehiiv newsletter platform.

It includes a set of browser automation scripts alongside a simple Express API layer, allowing tasks to be triggered programmatically or integrated into other workflows.

## Features

- Automates login and interaction with the Beehiiv platform via Playwright
- Supports browser automation across Chromium, Firefox, and WebKit
- Provides a helper API server (Node.js + Express) to expose automation triggers over HTTP
- Modular helper functions for reusable UI actions and interactions

## Use Cases

- Automating tasks like signing into Beehiiv or retrieving data
- Performing repetitive browser interactions in a testable, scriptable way
- Integrating automation using HTTP requests

## Tech Stack

- Playwright (browser automation)
- Node.js
- Express (API server)
- JavaScript
- Headless browser testing
